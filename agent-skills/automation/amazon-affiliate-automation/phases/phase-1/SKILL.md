# Phase 1: Product Scout

Focus on Amazon US and Home & Kitchen. Gather candidates only from lawful sources, normalise them into the CSV template, run the offline scorer and flag missing or stale evidence.

Never scrape Amazon, infer missing metrics or treat a high score as proof of demand or earnings. Only the user can approve a product for content.

Use the parent project's root `SKILL.md` for global compliance and approval rules.
