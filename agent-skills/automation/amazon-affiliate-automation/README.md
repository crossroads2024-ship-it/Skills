# Amazon Affiliate Automation

A portable, local-first workflow for Amazon US affiliate product research and short-form content production.

## Three phases

1. **Phase 1 — Product Scout foundation:** offline CSV scoring, evidence discipline and compliance rules.
2. **Phase 2 — Research operations:** SQLite history, CSV import, rankings, human decisions, daily run records and shortlist export.
3. **Phase 3 — Video Factory:** approval-gated scripts, storyboards, shot lists, voiceover, SRT subtitles and platform-specific copy.

## Project defaults

- Marketplace: Amazon US.
- Initial niche: Home & Kitchen.
- Budget target: $0. Prefer Python standard library and free/local tools.
- Windows 11 first.
- No scraping, bypassing access controls, unauthorised feeds or unapproved Amazon data collection.
- No paid services, account connections, purchases, deployment or publication without explicit authorisation.
- Human approval is mandatory before content production and again before publication.
- Only original, user-owned or appropriately licensed creative assets may be used.

## Requirements

Python 3.9+ for Phases 1 and 2. Phase 3 uses Python 3.9+ and the standard library. No network calls are made by the included engines.

## Important

This repository contains workflow and local tooling, not a live Amazon integration. Scores are prioritisation signals, not sales forecasts. The software does not verify source claims, legal compliance, footage rights or current programme terms. Human review remains essential.
